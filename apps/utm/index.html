01 About

Run real operating systems on your iPhone or iPad. UTM is an open-source (Apache-2.0) virtualization and emulation platform built on QEMU, capable of running Windows, Linux, classic Mac OS and dozens of other systems alongside your apps. Highlights: - QEMU v10.0.2 backend with support for dozens of CPU architectures (x86_64, ARM64, RISC-V, PowerPC and more) - Improved machine wizard with well-tested configurations such as Windows, Ubuntu, RISC-V64 Ubuntu, classic Mac OS 8.x/9.x and Windows 95/98 - Custom keyboard shortcuts (e.g. Ctrl+Alt+Del) sent directly to the VM from the Keyboard menu - App Intents automation with the Shortcuts app - Liquid Glass design on iOS 26 - Import and export .utm virtual machine bundles via the Files app - No jailbreak required; highest performance with JIT workarounds on supported iOS versions

Release notes
UTM 5.0.7 | Universal IPA

## Highlights
* (macOS) **DirectX graphics support for Windows**: Modern accelerated graphics for Windows 11 is now available on UTM for the first time. The driver is still experimental and games compatibility is currently limited.
* **Vulkan 1.3 graphics support for Linux**: Vulkan 1.3 is now supported on Linux guests with VirtIO Venus drivers in Mesa. Additionally, OpenGL 4.1 is supported with the new Apple Core OpenGL backend (macOS only).
* **Snapshots**: Save your VM at any point and go back to it later from the new Snapshots tab. Works with QEMU VMs on macOS and iOS 26, and with Apple Virtualization VMs on macOS 27.
* (macOS) **Apple Virtualization on macOS 27**: Pass USB devices through to your VM, turn on Secure Boot for Linux, run a VM without saving changes, and let VMs talk to each other with new networking modes.
* (iOS) **Better touch controls**: Gestures respond immediately, with new middle-click and right-drag actions and a new drag-to-scroll touch mode.
* (iOS) **iPhone Duo**: Fold your iPhone Duo like a laptop, and the bottom half becomes a keyboard or touchpad for your VM.

## Notes
* Suspended VMs may not resume correctly after updating. We recommend shutting down all VMs before you update UTM.
* The minimum supported versions are now macOS 12 and iOS 15.
* We now have a [development blog](https://blog.getutm.app)! Follow us for in-depth technical deep dives such as how we brought DirectX to QEMU.
* (macOS) To use the new graphics driver for Windows 11, we recommend a fresh install because the driver is still experimental and its use could lead to instability in the system. During the install of the guest tools, you will be prompted to select the experimental graphics driver. If you wish to install the new driver on a system that already is running the older display only driver, you need to run the uninstall script provided on the guest tools install ISO first.
* (macOS) Apple CoreGL backend does not support Vulkan or DirectX.
* Linux desktop rendering in Vulkan does not work due to lack of support for indirect draws for geometry shaders. Please configure your guest to use the older VirGL Gallium driver.

## Changes (v5.0.7)
* Updated the virglrenderer, MoltenVK and DXMT graphics backends with fixes for Windows 3D acceleration
* QEMU: Windows guests now use the host display's refresh rate instead of always 60 Hz, which also fixes 3D acceleration failing on displays faster than 125 Hz (#7820)
* QEMU: Fixed VirtIO GPU stalls that hung Windows at shutdown, stalled 3D benchmarks on Linux, and could leave the Windows 3D driver without a display
* Snapshots: Fixed saving and restoring the state of VMs with compressed disks (#7916)
* Localization: Updated Chinese (Hong Kong, Simplified) (thanks @changanmoon)
* (iOS 27.1) Support for iPhone Duo: the VM toolbar sits in the outer display's camera strip, and a new laptop mode turns the bottom half of the folded screen into a keyboard or touchpad
* (macOS) Fixed headless VMs keeping the Mac from sleeping after they were paused or stopped
* (macOS) Closing a VM window or quitting UTM while a VM runs now confirms with "Close" or "Quit" instead of "OK"
* (macOS) Fixed shaders using instancing or integer vertex attributes drawing incorrectly with the Apple Core OpenGL backend (#7944)
* (macOS) Updated the D3DMetal graphics backend with fixes for DirectX 12
* (macOS) Display: The option to use the area beside the camera housing in full screen is now available on macOS 12 and later (#6183)
* (macOS) Wizard: Fixed the Name field's focus ring being clipped on the summary page (thanks @dnicolson)
* (macOS 15) QEMU: Better performance on Apple Silicon with the Hypervisor.framework built-in interrupt controller
* (macOS) Scripting: Force stopping a paused VM is now allowed
* (macOS 27) AVF: Explain when a USB device such as a webcam or phone can't be passed through, instead of showing "VZErrorDomain error -6" (#7914)
* (macOS) Guest Agent: Fixed an issue
