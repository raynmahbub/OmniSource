01 About

Saber is a free and open-source handwritten notes app built with Flutter. Write with your finger or Apple Pencil as if on paper, organize notes into folders, keep them private with encryption, and sync across devices using its optional Nextcloud-based sync — no vendor lock-in.

Device compatibility: choose a profile on the catalog page.

02 Install with

Pick your client. Links are generated from the catalog on every build — never hard-coded.

KsignCompatibleTap to add the source to Ksign. If nothing happens, open Ksign sources and paste the URL.
LiveContainerCompatibleTap to add the source to LiveContainer. If nothing happens, open LiveContainer → Settings → Sources and paste the URL.
